# Status

CleanPrompt is currently a working prototype with:

- a functional browser extension runtime
- local prompt redaction and policy-aware review flows
- a demo control plane for managed-mode evaluation
- automated tests for core contracts and browser-surface smoke behavior
- packaging and verification scripts for evaluation handoff

Current positioning:

- suitable for controlled demos and technical evaluation
- not yet positioned as a production SaaS release

Areas still in progress:

- selector resilience across supported AI surfaces
- broader browser-level validation
- production-grade control-plane capabilities
- release and deployment hardening beyond pilot workflows
