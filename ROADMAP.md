# Roadmap

This file summarizes the public-facing direction for CleanPrompt.

## Near Term

- Stabilize supported-site selectors and content-script compatibility
- Expand browser-surface regression coverage
- Improve managed-mode setup and admin-console usability
- Harden packaging and release verification flows

## Next

- Strengthen control-plane contract coverage and validation
- Improve policy management and rollout ergonomics
- Refine audit/reporting views for metadata-only insights
- Add clearer deployment guidance for pilot environments

## Longer Term

- Mature multi-tenant control-plane architecture
- Strengthen authentication and admin controls
- Broaden supported enterprise deployment paths
- Move from prototype evaluation workflows toward production readiness
